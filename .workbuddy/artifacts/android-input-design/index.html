输入框重设计 · 4 个方案

每套方案都在浅色与深色下各渲染一屏，包含 6 种真实状态：空值占位、密码掩码、聚焦输入中、 校验错误、多行备注、搜索栏。配色全部取自项目 Color.kt / Theme.kt 的令牌，不是随手编的颜色。

现状：全圆角胶囊 + 2dp 阴影

1px 透明边框 + 阴影 + RoundedCornerShape(50)。问题在于：默认态没有任何边界，靠阴影撑形状，看起来像一颗"按钮"；只有聚焦时才突然出现一圈 1dp 蓝边，视觉跳变明显。

深色下阴影几乎不可见

深色模式这一屏尤其能说明问题：2dp 阴影在深色底上完全读不出来，输入框和背景糊在一起，只剩一个聚焦蓝边可辨。

A

填充胶囊 Fill Capsule

Material 3 Filled 风格：实色填充、无描边、无阴影，圆角拉满。聚焦时填充变亮并出现 2dp 内描边。最轻、最"现代"，和现有 AppButton 胶囊语言一脉相承。

方案 A · 深色

优点：改动最小（只换 colors/shape/elevation）、和按钮同族、无边框所以没有"描边粗细"的脏边问题。缺点：错误态只能用内描边表达，红框在深色底上略吃力。

B

柔和描边卡 Soft Outline

白底（深色为表面色）+ 常显 1dp 极淡描边 + 14dp 圆角，去掉阴影。聚焦时描边转主色并外扩一层 4dp 柔光晕。边界始终清晰，最稳、最像"表单"。

方案 B · 深色

优点：深浅色都不出错，状态区分最明确（默认灰边 / 聚焦蓝边+光晕 / 错误红边+红光），也最容易通过无障碍对比度检查。缺点：圆角从 50 降到 14，和胶囊按钮不完全同族，需要接受"按钮圆、输入框方"的层次差异。

C

浮动标签盒 Floating Label

标准 M3 Outlined：18dp 圆角，标签从边框上"切"出一块，聚焦转主色。省掉框外那一行标签的垂直空间，信息密度最高，适合表单字段多的页面。

方案 C · 深色

优点：专业感最强、省空间、标签和输入框是一体。缺点：深色下标签要靠背景色"挖洞"，一旦放在 AppPanel 卡片上，挖洞颜色必须跟着面板走（实现时要用 `LocalAppSurfaceColor` 之类传色，否则会出现一块补丁）。

D

图标槽 Icon Slot

16dp 圆角、浅填充，左侧一个 44dp 主色图标槽，聚焦时图标槽填充为实色主色。视觉重心最强，仪式感最足，适合登录、绑定这类"少而重要"的字段。

方案 D · 深色

优点：辨识度高、聚焦反馈最明显（整块图标槽点亮）。缺点：不适合全 App 铺开 —— 搜索框、多行备注、无图标的普通输入框用它反而累赘，实际落地时只能"重点表单用它、其余用 A 或 B"。
