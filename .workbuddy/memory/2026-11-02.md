- **误入库的编译产物**：`apps/android-app/androidx/**/*.class`（2 个，来自提交 `0832a85「优化」`）已 `git rm --cached` 并从磁盘删除；`.gitignore` 增补 `/androidx/`、`*.class`。

### 结论：AppViewModel 拆分暂缓

`iot` 域读侧散在 OperationsScreen / ScenesScreen / ToolsScreen，写侧在 `ScenesController`，加载态由 `launchRefresh` 集中维护在 `AppUiState.sectionLoadStates` —— 抽 `FeatureStateHolder` 会连带改投影签名与刷新指示器语义，无设备侧用例兜底时不建议一次做完。下一刀的建议顺序：`backup + diagnostics + ct8`（消费方只有 OperationsScreen）→ `iot` → 收缩 `AppUiState`。
