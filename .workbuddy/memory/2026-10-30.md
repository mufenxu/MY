## Android 分区标题副标题右对齐修复

- 现象：`今日`/`设备` 等页面的分区标题带（浅底胶囊）中，右侧说明文字（如「已接入的应用快捷访问」「常用灯光与插座」）停在标题栏中间，右侧留白。
- 根因：`ui/components/display/AppSectionHeader.kt` 中副标题用 `Modifier.weight(1f, fill = false)`。Compose 的 `fill = false` 只把子项上限设为权重份额（约 50%），按内容收缩后剩余空间不会分给兄弟节点，整行按 start 排布 → 副标题右侧出现空隙。`textAlign = TextAlign.End` 形同虚设。
- 修复：副标题改为 `Modifier.weight(1f)`（填满份额），`TextAlign.End` 才能贴到标题栏内右边缘（有 `trailing` 时贴在其左侧 8dp）。
- 覆盖面：该组件是唯一分区标题实现，53 处调用（`OverviewSectionTitle` / `ToolSectionTitle` / `ProfileSectionTitle` / `AndroidReleaseSectionTitle` / `SettingsSectionTitle` 等包装器全部委托到它），一处修复全局生效。`AndroidReleaseScreen` 的骨架占位用 `Arrangement.SpaceBetween`，本身已正确。
- 附带：`app/src/debug/.../DesignSystemPreviews.kt` 从未覆盖 `AppSectionHeader`，补了两条预览（是否带 trailing 各一），作为对齐回归的目视锚点。
- 验证：`npm run check:android-design` 通过（136 文件）；`./gradlew :app:compileDebugKotlin --offline` BUILD SUCCESSFUL（需 `JAVA_HOME=C:/Users/25912/.jdks/ms-17.0.18`，本机 PATH 无 java）；无设备（adb devices 为空），未做真机渲染验证。
- 保持 50/50 份额的原因：与修复前副标题可用宽度完全一致，只改位置，不引入新的省略风险。
