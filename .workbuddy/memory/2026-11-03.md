# 2026-11-03

## 登录页插图（3D 黏土风场景图）

- 用户最初想把一张 1440×1440 的 3D 场景插图当安卓应用图标，评估后放弃：自适应图标安全区只有 66/108，图里 8 个物体铺到 0.47R，直铺会被裁掉底部色块；缩进安全区又变成"图标里贴缩略图"。保留现有 S 品牌标（`platform_logo.png`）。
- 改为用作登录页插图：
  - 新增 `app/src/main/res/drawable-nodpi/login_hero.webp`（1024×1024，49 KB）。源图外侧有烘焙的灰阴影，裁 46px 内缩后用 13.2% 圆角 alpha 遮罩切掉，避免白底板外圈留灰边。
  - `LoginDecoration.kt` 新增 `LoginHero(size, modifier)`：`ContentScale.Fit` + 与卡片同源的 `dropShadow`（圆角 13%），深色主题 `graphicsLayer { alpha = 0.86f }` 压暗。
  - `LoginScreen.kt`：展开宽度（双栏）左栏 300dp 置于 `LoginHeader` 上方；手机竖屏 140dp，受 `showHero`（`heightSizeClass != Compact`）控制，横屏/矮屏不展示以免挤出表单。
- 尺寸选择依据：手机首屏预算 ~760dp，140+24+130+28+380 ≈ 702，加页脚仍不滚动。
