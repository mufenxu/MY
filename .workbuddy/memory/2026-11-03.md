## 登录页背景视频（当前生效）

素材：`C:\Users\25912\Desktop\login-bg-light-v2\`，装机版 phone 1080×1920 / tablet 1920×1080，各 2.2MB / 2.0MB，H.264 avc1、24fps、20s、**无音轨**。479 帧 = 240+240−1，是「正放 10s + 倒放 10s」回旋版，首尾同帧，天生可无缝循环。

- `res/raw/login_bg_phone.mp4`、`res/raw/login_bg_tablet.mp4`（装机版原样拷入；本机无 ffmpeg，未二次压缩）。
- `drawable-nodpi/login_poster_phone.webp`、`login_poster_tablet.webp`：海报 PNG 759KB/1.1MB 转 WebP 后仅 19KB/17KB。
- `LoginBackdrop.kt`（新）：浅色主题播视频，`ExoPlayer` + `REPEAT_MODE_ONE`（**不能用 VideoView.setLooping，回环必顿**），`volume=0`；`PlayerView` 关控制器、快门透明；海报垫底，`onRenderedFirstFrame` 后 400ms 淡出（海报画在上层，不依赖 surface 透明）。`LocalLifecycleOwner` 监听 ON_STOP 暂停；`ANIMATOR_DURATION_SCALE == 0` 时不播只留静态帧。
- 铺法：竖屏 `fillMaxWidth().aspectRatio(9f/16f)` 贴顶（**不做 zoom**——素材里地球、柱状图贴着左右边缘，zoom 要切 10%），底边 160dp 渐隐到 `ColorTokens.LoginBackgroundLight`；横屏用平板版 `fillMaxSize` + `RESIZE_MODE_ZOOM`（16:9 对 16:10 只切 5%）。素材按 `LocalConfiguration.orientation` 选，不看 `-land` 限定符（平板竖屏要放竖版）。
- 深色主题无配套素材，**不播视频**，沿用 `LoginAmbientBackground` 几何底纹。
- 版面照用户给的 `效果示意-卡片合成预览.png` 改：竖屏卡片 `Alignment.BottomCenter` 沉底、去掉 `LoginHeader` 标题；展开宽度左栏放 `BrandMark`，因背景动态、文字对比度不可控，垫 `surface.copy(alpha = 0.72f)` 圆角面板。
- 依赖：`androidx.media3:media3-exoplayer` + `media3-ui` 1.11.1。`PlayerView` 是 `@UnstableApi`，需 `@OptIn(markerClass = [UnstableApi::class])`，否则 lint 报 UnsafeOptInUsageError。
