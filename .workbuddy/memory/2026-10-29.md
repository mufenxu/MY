## Android 优化升级落地（本轮实改）

**验证口径**：`:app:compileDebugKotlin`、`:app:testDebugUnitTest`、`:app:assembleRelease`（R8）、`npm run check:android-design` 全部通过。本机 `JAVA_HOME=D:/My-ruanjian/Android Studio/jbr`。

### APK 体积：71MB → 37MB（-48%）
- 根因：ML Kit 捆绑原生库横跨 4 个 ABI——OCR `libmlkit_google_ocr_pipeline.so` 约 41MB、条码 `libbarhopper_v3.so` 约 20MB。
- 改法：`app/build.gradle.kts` 的 `defaultConfig.ndk.abiFilters` 只保留 `arm64-v8a` + `armeabi-v7a`，去掉仅模拟器需要的 x86/x86_64。
- **不要改用 ABI splits**：自更新清单 (`latest.json`) 是单 APK + 单 sha256 契约，拆分会直接破坏升级链路。这是本轮明确放弃的一项。

### 依赖升级（受 compileSdk 36 约束）
- OkHttp `4.12.0 → 5.2.3`、Coil `2.7.0 → 3.4.0`（包名 `coil.*` → `coil3.*`，`coil.decode.SvgDecoder` → `coil3.svg.SvgDecoder`，新增 `coil-network-okhttp`）。
- **坑**：OkHttp 5.5.1 与 Coil 3.6.3 的 AAR 元数据要求 `compileSdk 37`，本机只装到 36（且 AGP 8.13.2 上限即 36 附近）。升到 37 需装 SDK，故退到 5.2.3 / 3.4.0。
- Coil 3 版本号要看清：`3.4.1`/`3.4.2` 并不存在（那是 OkHttp 的版本序列），Coil 3 只有 3.4.0 → 3.5.0 → 3.6.x。
