## 第二批：Web favicon + 小程序 logo + 考试系统标也换成新图（2026-11-19 中午，用户指定"4、6、7"）

用户按清单编号指定只换 04（Web favicon）、06（小程序 logo）、07（exam-api 的 S 标），02/03/05/08 保持不变。

**关键坑：只换 `favicon.png` 是不够的。** 7 个 Web 入口页面全部优先引用 `favicon.svg`，而且 `favicon.svg` 还被当成页面 logo 直接使用：
- `apps/admin-console/index.html` 第 21 行 `<img src="/favicon.svg">`
- `apps/official-website/index.html` 第 324 行 同上
- `apps/core-admin/src/components/MainLayout.jsx` 第 58 行 同上
- `apps/admin-console/src/client/brand.js` 的 `PLATFORM_BRAND_ICON = '/favicon.svg'`

所以必须 **png + svg + ico 三件套一起换**，否则页面 logo 仍是旧图。

替换口径：
- 6 个目录（admin-console / core-admin / exam-admin / official-website / iot-service / exam-api）各写 `favicon.png`(512² RGBA 209KB，与旧文件同规格) + `favicon.svg` + `favicon.ico`(16/32/48/64/128/256 六档)。
- **svg 内嵌图用 256² 而不是 512²**：512² 内嵌会让 svg 涨到 279KB，256² 是 96KB（旧文件 76KB）。`<image>` 的 width/height 仍写 512（viewBox 单位），只是 href 里 PNG 实际像素 256。
- 小程序两处 logo 写 256²：`apps/exam-miniapp/miniprogram/assets/admin-logo.png`、`apps/smart-campus-miniapp/miniprogram/pages/login/logo.png`。
- `apps/official-website/index.html` 的 5 处 `?v=20261104_1` 全部改成 `?v=20261119_1`（该站历史上因缓存踩过坑，其他三站没有版本参数）。
- 校验：png / svg 内嵌图 / ico 全部与新图逐字节比对通过；16px 下 ∞ 仍可辨认。
- 检查：`check:conventions`、`check:miniapps`、`check:website`（含 vite 构建）全绿。
