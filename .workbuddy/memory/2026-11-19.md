## 续：campus-service / iot-service 两页也统一了（接上一节，用户要求「试试引 tokens.css + components.css，不行就算了」）

**结论：整包引入不成立，改成单组件分发。** 三条硬理由，别再试：

1. `packages/pearl-tokens` 在本仓库不是 workspace 依赖，两服务的 Dockerfile 只 `COPY` 自己的 `public/src/scripts`（packages 仅 platform-auth、api-contract），直接 `<link>` 包内路径线上必 404。
2. `components.css` 2195 行，含 `.btn/.field/.page-view/.service-status` 等通用类；两页现在虽然没用到这些类名，但整包注入等于给未来埋冲突。
3. 主题语义是反的：`tokens.css` 是 `:root` 亮 + `:root[data-theme="dark"]` 暗；campus 用 `body.dark-theme`，iot **默认暗色**（`data-theme="light"` 才是亮）。`--surface/--text/--shadow` 在 campus 还有同名不同义（campus 的 `--surface` 是颜色，pearl 的是渐变）。

**做法**：`generate.mjs` 从 `components.css` 的 `/* --- pearl-console-switch:start/end --- */` 标记之间**原样提取**组件规则，生成到
`services/campus-service/public/console-switch.css`、`services/iot-service/public/console-switch.css`，各自前面插入按本页色板映射的令牌块（campus 亮 + `body.dark-theme`；iot 暗 + `[data-theme="light"]`）。`npm run generate` 生成、`check` 里的 `--check` 卡同步——**改按钮只改 components.css，跑一次 generate**。

- **尺寸不强行统一**：campus 桌面端顶栏会变成左侧栏，动作区是一列 46px 整宽按钮，32px 胶囊塞进去明显矮一截（实测 250×32 vs 250×46）。所以两页只换「材质」（`--surface` 底 + `--line-strong` 描边 + `--edge/--e1` + hover 描边转本页强调色），高度/内距/字号交给宿主 `.actions a` / `.button`。core-admin、exam-admin 仍是 32px 胶囊。
- **≤768 两页故意不同**：campus 横向动作行拥挤 → 收成 32×32 方钮（要 `box-sizing:border-box` + `padding:0` 才真的 32，两页都没有全局 border-box）；iot 窄屏 `.topbar-actions` 会竖排成整宽列，收成纯图标会变成一条空条 → 保留图标+文字、`width:auto`。
- campus 用 `#platformConsoleLink.pearl-console-switch` 提权盖住 `.actions a`(0,1,1) 与 `.actions a.ghost`(0,2,1) 的 `background:transparent`；iot 同理用 `#platform-console-link` 盖 `.button-secondary`。两页都**保留原有 class**（`admin-action ghost` / `button button-secondary hidden`），因为 `hidden` 靠 `display:none !important`、布局靠这些类，删了会串。
- 图标 SVG 现在有 **5 处内联副本**（core-admin、exam Dashboard、exam ExamDetail、campus、iot），改形要一起改，`grep 'M8 2.1 13.9 5'` 一下就能找全。
- 文案两页都收敛成 title/aria-label「返回统一控制台」+ 可见「统一控制台」。
- `services/campus-service/test/asset-budget.test.js` 新增 `public/console-switch.css: 4KB`（生成物 3090B）；campus 的 `styles.css` 只剩 164B 余量、`index.html` 剩 1.4KB，**新样式必须走独立文件**，不能再往 styles.css 里塞。
